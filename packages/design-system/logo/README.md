# Tashi logo

A plus whose stem sweeps like a brush stroke, with a drop falling away from it. Flat Sora tones with one shadow, where the stem casts onto the bar. Use the bare mark everywhere except where a platform needs a filled square (home-screen and install icons); see D-10. Every SVG here is generated by `generate.py`; edit the script, never the SVGs.

## Files

| File | Use |
| --- | --- |
| `tashi-mark-light.svg` | Logo without a border, for light backgrounds. Transparent, 360×360. |
| `tashi-mark-dark.svg` | Same, for dark backgrounds. |
| `tashi-icon-light.svg` | App icon: the mark on a white rounded tile, 1024×1024. |
| `tashi-icon-dark.svg` | App icon on a Sora 950 tile. |
| `tashi-square-light.svg`, `tashi-square-dark.svg` | App icon on a square background that bleeds to the edges, for home screens that round or mask icons themselves. |

## Regenerating

From the repository root:

```sh
nix develop -c pnpm --filter @tashi/design-system logo
```

It needs Python and `rsvg-convert`, both in the flake's dev shell. Besides writing the files above, it updates what the app ships, so commit those together with the change to the script:

- `packages/frontend/src/assets/`: the marks used by the `Logo` component. Inside the app the logo has no tile (D-10).
- `packages/frontend/public/favicon-{light,dark}.svg`: browser tab icons, also the bare mark.
- `packages/frontend/public/` PNGs for installing the app, all in the light palette since installed icons cannot follow the system theme:
    - `apple-touch-icon.png` (180 px, square): iOS home screen.
    - `icon-192.png` and `icon-512.png` (rounded tile): the manifest's regular icons.
    - `icon-maskable-512.png` (square): Android launchers that crop icons to their own shape. The mark stays inside the central safe circle.

`packages/frontend/public/manifest.webmanifest` is written by hand: update its colours if the app's background tokens change. `index.html` links it with `crossorigin="use-credentials"`: the deployment sits behind Cloudflare Access, and a manifest fetched without cookies gets the login redirect instead, which makes the app uninstallable.

## Tweaking

- Colours come from `../tokens/tokens.json`. `PALETTES` maps each part of the logo to a primitive such as `sora.600`, so changing the Sora scale there changes the logo too. The steps the logo needs beyond the UI roles (200, 400, 500, 700, 800) live in the same scale.
- `CAST_OPACITY` sets how dark the stem's shadow on the bar is, per mode.
- Geometry lives in the constants under `PALETTES`, on a 360×360 grid. `DROP_BELLY` sets where the drop's underside leaves the bulb and meets the tip, in degrees; values that are too far apart make the underside wavy.
